# Employee Performance & Salary Analysis Using NumPy

A Python project that analyzes employee performance and calculates salary increments using **NumPy**. It evaluates average performance, assigns performance ratings, identifies top and low performers, and generates a summary report.

---

## Features
- Calculates **average performance** per employee  
- Assigns **ratings**: Excellent, Good, Average, Poor  
- Calculates **salary increments** based on performance  
- Identifies **top and lowest performers**  
- Generates a **clean, readable report**
